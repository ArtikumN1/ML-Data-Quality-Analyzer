# Dataset Profiler & Data Quality Checker

Инструмент для автоматического анализа CSV-датасетов перед использованием в машинном обучении.

Проект выполняет первичный анализ данных (EDA) и проверяет качество датасета:

- анализ структуры данных;
- определение типов признаков;
- поиск пропущенных значений;
- проверка числовых признаков;
- обнаружение отрицательных значений;
- поиск выбросов методом IQR.

Проект написан на Python с использованием библиотеки Pandas.

---

# Возможности проекта

## 1. Загрузка данных

Модуль `data_loader.py` отвечает за загрузку CSV-файлов.

Пример:

```python
df = load_csv("data/raw/example.csv")
```

После загрузки данные преобразуются в объект `pandas.DataFrame`.

---

## 2. Анализ структуры датасета

Класс `DatasetProfiler` выполняет базовый анализ данных:

- количество строк;
- количество столбцов;
- список названий признаков;
- типы данных.

Пример:

```python
{
    "rows": 1000,
    "columns": 10,
    "column_names": [
        "age",
        "salary",
        "city"
    ]
}
```

---

## 3. Определение типов признаков

Система автоматически определяет тип каждого признака:

- numeric — числовой признак;
- categorical — категориальный признак;
- text — текстовый признак.

Пример:

```
age: numeric
salary: numeric
city: categorical
description: text
```

---

# Проверка качества данных

## 4. Анализ пропущенных значений

Модуль:

```
validators/missing.py
```

Проверяет наличие пропусков.

Для каждого признака выводится:

- количество пропущенных значений;
- процент пропусков от общего размера датасета.

Пример результата:

```python
{
    "salary": {
        "count": 15,
        "percentage": 1.5
    }
}
```

---

## 5. Проверка числовых признаков

Модуль:

```
validators/numeric.py
```

Выполняет анализ числовых колонок.

Проверки:

### Отрицательные значения

Поиск значений, которые могут быть ошибочными:

Пример:

```
age = -5
salary = -1000
```

---

### Выбросы

Для обнаружения выбросов используется метод IQR.

Формулы:

```
IQR = Q3 - Q1

Lower Bound = Q1 - 1.5 * IQR

Upper Bound = Q3 + 1.5 * IQR
```

Значения за пределами диапазона считаются потенциальными выбросами.

# Установка

Клонировать репозиторий:

```bash
git clone <repository_url>
```

Перейти в директорию проекта:

```bash
cd ml-data-profiler
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать окружение:

Windows:

```bash
.venv\Scripts\activate
```

Linux/Mac:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Основной поток:

```

    ↓

    ↓

    ↓

    ↓

```

Такой подход позволяет:

- добавлять новые проверки;
- расширять функциональность;
- повторно использовать отдельные модули.

# Цель проекта

Цель проекта — создать инструмент предварительной проверки данных перед обучением ML-моделей.

Качество данных напрямую влияет на качество модели, поэтому автоматический анализ позволяет быстрее находить проблемы:

- пропуски;
- некорректные значения;
- выбросы;
- ошибки типов данных.

Проект является частью подготовки к построению полноценного ML pipeline.
